LidKeep —— 关屏但不睡眠

安装器会放入两项：

  • LidKeep.app → /Applications（菜单栏常驻，热键零授权）
  • lidkeep 命令行工具 → /usr/local/bin

安装完成后菜单栏会出现一个月亮图标，点击可展开菜单。

使用

  • 点击菜单栏图标 → 打开菜单（开关显示 / 设置 / 热键自检 / 退出）
  • 默认热键在「设置」里配置；热键走系统全局热键，无需任何隐私授权
  • 远程（SSH）可用：lidkeep off / lidkeep on

关于签名

本安装包未使用付费开发者证书签名（ad-hoc）。若首次打开 App 被系统拦截， 在「访达」中对 LidKeep.app 右键 → 打开 即可；安装脚本已尝试自动清除隔离标记。

卸载

源码方式：make uninstall
手动方式：删除 /Applications/LidKeep.app 与 /usr/local/bin/lidkeep，可选清理 ~/Library/Application Support/LidKeep（配置与日志）。
